# Social-Media-Engagement-Analytic


A data analytics project focused on analyzing social media engagement patterns, audience behavior, and content performance using Python.

## 📌 Project Overview

This project explores a dataset containing **5,000 social media records** to identify patterns in likes, comments, shares, impressions, watch time, and engagement rates.

The main objective is to understand which content types, categories, audience segments, and posting factors are associated with higher engagement.

## 📊 Dataset Information

- **Dataset:** Social Media Engagement Dataset
- **Records:** 5,000
- **Original Features:** 19
- **Data Format:** CSV

### Key Attributes

- **User Information:** Age, Gender, Country
- **Content Information:** Post Type, Post Category, Hashtags
- **Engagement Metrics:** Likes, Comments, Shares, Impressions
- **Performance Metrics:** Engagement Rate, Watch Time
- **Additional Attributes:** Sentiment, Device Type, Verification Status, Posting Date

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## 🔄 Project Workflow

1. **Data Import and Exploration:** Loaded the dataset and examined its structure, columns, data types, and statistical information.
2. **Data Cleaning:** Handled missing values, removed duplicate records, corrected data types, and standardized categorical values.
3. **Exploratory Data Analysis:** Analyzed distributions, unique values, correlations, and group-wise statistics.
4. **Feature Engineering:** Created engagement score, hashtag count, date-based features, and additional analytical variables.
5. **Statistical Analysis:** Calculated mean, median, mode, standard deviation, variance, percentiles, skewness, and kurtosis.
6. **Data Visualization:** Created charts using Matplotlib, Seaborn, and Plotly.
7. **Business Insights:** Compared post types, categories, countries, age, sentiment, verification status, posting hours, and devices.

## 🔍 Key Analysis Areas

- Engagement performance by post type and category
- Country-wise engagement patterns
- Age and audience engagement
- Verified vs. unverified user engagement
- Posting-hour performance
- Device-wise watch time
- Sentiment and engagement relationships
